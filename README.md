# lp-10793-exemplos — Linguagens de Programação (12ºPI)

Exemplos do professor da UFCD 10793 Fundamentos de Python, mostrados nas aulas. É público: qualquer aluno pode consultar e clonar.

**Começa pelo [GUIA.md](GUIA.md)** (também em [PDF](GUIA.pdf)): tem os passos para criares a conta no GitHub e o teu repositório `lp-10793`, instalares e configurares o Git e o VS Code, e trabalhares com commit, push e pull no VS Code.

## Como está organizado

```
lp-10793-exemplos/
  README.md          este ficheiro
  aulas/             o exemplo de cada aula
    aula-02.ipynb
    aula-03.ipynb
    ola.py
  fichas/            as resoluções das fichas
    ficha-05.ipynb
```

A estrutura é a mesma que se pede no repositório de cada aluno: `aulas/` com `aula-NN.ipynb` e `fichas/` com `ficha-NN.ipynb`, sempre com dois algarismos, sem espaços, sem acentos e em minúsculas.

## Como usar

```
git clone https://github.com/joaofonsecasynget/lp-10793-exemplos.git
```

Ou, se já o tiveres clonado, `git pull` antes de cada aula.

Copiar daqui para o teu repositório é permitido e recomendado: o que conta é perceberes o código e conseguires explicá-lo.
